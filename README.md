# Director OS

A lightweight terminal-based operating system for technology leaders.

## Features

- Task tracking
- Dependency tracking
- Accomplishment tracking
- Daily operating log
- Reopen completed work
- Textual TUI

## Keyboard Shortcuts

| Key | Action |
|------|---------|
| A | Add Task |
| D | Complete Task |
| U | Reopen Task |
| R | Refresh |
| Q | Quit |

## Running

```bash
pip install -r requirements.txt

python app.py
